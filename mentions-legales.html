DNDVDL-MAP est un outil interne de gestion de baies informatiques, à usage restreint à une équipe technique identifiée. Le site n'est pas référencé par les moteurs de recherche (balise noindex) mais reste, comme toute page GitHub Pages, techniquement accessible publiquement — les présentes mentions s'appliquent donc pleinement.

03

Données personnelles — RGPD

Comptes utilisateurs : l'accès à l'outil nécessite un compte (email + mot de passe géré par Supabase Auth). Chaque compte porte un statut d'approbation (pending / approved / refused) et un rôle (admin / editeur / lecteur) déterminant les droits d'accès.

Données métier (baies, équipements) : ces données ne sont pas stockées en base — elles vivent dans un fichier JSON importé/exporté manuellement par les utilisateurs. Seules les données de compte transitent par Supabase.

Finalité : contrôle d'accès à un outil de gestion d'infrastructure réseau, réservé à une équipe technique.

Base légale : intérêt légitime à restreindre l'accès à un outil sensible (art. 6.1.f du RGPD).

Durée de conservation : les comptes sont conservés tant que la personne fait partie de l'équipe autorisée ; un compte refusé (refused) ou obsolète peut être supprimé sur demande.

Conformément au RGPD, toute personne concernée dispose d'un droit d'accès, de rectification et de suppression de ses données de compte. Pour l'exercer : shamsetdean@gmail.com.
